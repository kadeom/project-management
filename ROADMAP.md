# Roadmap

## Сейчас

- Структура репозитория приведена к референсу `agent-harness`.
- Данные, расчёты и артефакты собираются из `project.yaml`.
- Документация: архитектура, ADR, чек-лист, справочники.

## Дальше

- CI: pytest и ruff на каждый push.
- JSON Schema для `project.yaml` с проверкой в тестах.
- Проверка актуальности `.mpp` относительно XML.
- Типизация пакета и `py.typed`.

## Позже

- Поддержка второго учебного проекта без копирования репозитория.
- Экспорт отчёта в PDF.
- Проверка сборки на всех поддерживаемых версиях Python.
