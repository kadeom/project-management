## Правила

- Документ отвечает на один вопрос. Ссылки ведут на существующие файлы.
- Числа и имена артефактов берутся из `project.yaml` и `src/pm/paths.py`.
- Решения оформляются в `architecture/adr/`, а не в переписке.
- Руководство для студента — в `guides/`, справочник — в `reference/`.
