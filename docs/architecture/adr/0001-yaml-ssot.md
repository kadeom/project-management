# 0001. `project.yaml` — единственный источник данных

- Статус: accepted
- Дата: 2026-10-27
- Заменяет: —

## Контекст

Задачи, ресурсы, ставки и связи нужны в XML, расчётах, отчёте и тестах. Ручное
дублирование расходится: дата в отчёте перестаёт совпадать с датой в MS Project.

## Решение

Все данные проекта хранятся в `project.yaml`. `src/pm/model.py` загружает файл и
строит типизированную модель. Остальные модули получают только `Project`.
Артефакты в `out/` не редактируются вручную: их пересобирает `build.py`.

## Последствия

- Изменение плана — одна правка YAML и пересборка.
- Схема проверяется моделью и тестами, а не отдельным редактором.
- Разделы отчёта, которые дублируют текст (например, рабочее время), остаются
  исключением и правятся синхронно.

## Альтернативы

| Вариант | Почему отклонён |
|---|---|
| XML как источник | бинарный формат, сложно рецензировать |
| Таблицы в `.docx` | нет машинной проверки |
| База данных | избыточна для учебного проекта |
