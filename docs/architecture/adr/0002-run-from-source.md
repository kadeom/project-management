# 0002. Запуск из исходников через `src/` в `sys.path`

- Статус: accepted
- Дата: 2026-10-27
- Заменяет: —

## Контекст

На учебной ВМ нет гарантированной установки пакета. `pip install -e .` требует
pip, прав и сети. При этом пакет должен лежать в `src/`, как в референсной
структуре.

## Решение

`build.py`, тесты, `scripts/` и `automation/` добавляют `src/` в начало
`sys.path`. `pyproject.toml` задаёт `package-dir = {"" = "src"}` и
`pythonpath = ["src"]` для pytest. Установка остаётся возможной, но не
обязательной.

## Последствия

- Клон работает сразу после установки зависимостей.
- Пути внутри пакета считаются от `Path(__file__).parents[2]`.
- Пакет нельзя использовать как библиотеку вне клона без установки.
- Импорт `pm` в ноутбуке вне корня репозитория не сработает.

## Альтернативы

| Вариант | Почему отклонён |
|---|---|
| Плоский `pm/` в корне | расходится с референсной src-структурой |
| Обязательный `pip install -e .` | лишний шаг и сеть на ВМ |
| `PYTHONPATH` вручную | забывается, ошибки непонятны |
