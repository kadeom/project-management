# 0003. Детерминированная сборка и `MANIFEST`

- Статус: accepted
- Дата: 2026-10-27
- Заменяет: —

## Контекст

`out/` закоммичен. Если сборка нестабильна, каждый прогон создаёт diff, а
проверить отчёт по git становится невозможно. Имена артефактов нужны в сборке,
тестах и документации.

## Решение

- Версии MPXJ и JPype1 закреплены точно.
- GUID кодов структуры детерминированы.
- JSON и Markdown пишутся с LF.
- `src/pm/paths.py` хранит имена и `MANIFEST`; литералы запрещены.
- Тест `test_build_deterministic` сравнивает два прогона.
- `.docx` сравнивается по содержимому zip, без времени архива.

## Последствия

- Diff в `out/` означает изменение модели или кода, а не шум.
- Обновление MPXJ требует осознанной пересборки и проверки XML.
- Новый артефакт добавляется в `MANIFEST`, иначе тест его не увидит.

## Альтернативы

| Вариант | Почему отклонён |
|---|---|
| Не коммитить `out/` | студент не получит готовые файлы |
| Свободные версии зависимостей | XML меняется между версиями |
| Случайные GUID | diff при каждом прогоне |
