# 0004. `.mpp` и `out/` закоммичены

- Статус: accepted
- Дата: 2026-10-27
- Заменяет: —

## Контекст

`.mpp` создаёт только MS Project. На Linux и в CI его не собрать. Студенту нужен
файл, который открывается двойным щелчком. XML остаётся источником истины.

## Решение

- `out/*.xml`, `expected.json`, `analysis.md` и `.docx` коммитятся.
- `.mpp` коммитятся как удобный бинарь, но не входят в `MANIFEST`.
- Пересборка `.mpp` — Windows-шаг `scripts/xml_to_mpp.py` или `build.py --full`.
- Бинарные расширения помечены в `.gitattributes`.

## Последствия

- Репозиторий содержит несколько мегабайт бинарей.
- `.mpp` может отставать от XML; актуальность проверяется вручную.
- Клон без Git LFS всё равно работает.
- История git не может показать diff `.mpp`.

## Альтернативы

| Вариант | Почему отклонён |
|---|---|
| Git LFS | дополнительная настройка на ВМ |
| Только XML | студенту нужен ручной импорт |
| Релизы GitHub | ссылки устаревают, нет офлайн-клона |
