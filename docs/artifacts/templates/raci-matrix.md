# RACI-матрица

Проект: {{ project.name }}. Версия: 1.0.

R — выполняет, A — принимает решение, C — консультирует, I — информируется.

| Работа / роль | Руководитель | Заказчик | Аналитик | Разработчик | Тестировщик |
|---|---|---|---|---|---|
| Устав проекта | A/R | C | C | I | I |
| Сбор требований | A | C | R | C | I |
| Архитектура | A | I | C | R | C |
| Реализация | A | I | C | R | C |
| Тестирование | A | I | I | C | R |
| Приёмка | C | A/R | I | I | I |

## Проверка

- В каждой строке ровно один A.
- Нет строки без R.
- Заказчик не выполняет работы, а принимает результат.
- Если A и R у одного человека — это осознанное решение, а не ошибка.
