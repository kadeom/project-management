# Руководства

  подсказки для защиты.
- [`additional-assignment.md`](additional-assignment.md) — сборка двух вариантов ДЗ.
- [`../../README.md`](../../README.md) — быстрый старт и автоматический конвейер.

## Как пользоваться

1. Соберите артефакты: `python build.py`.
2. Откройте `out/01_plan_lab1-2.mpp` или XML.
3. Идите по чек-листу и сверяйте числа с `out/analysis.md`.
4. Вставьте скриншоты в отчёт или запустите `python build.py --full` на Windows.
