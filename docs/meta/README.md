# Метаданные

| Файл | Назначение |
|---|---|
| [`tasks/`](tasks/README.md) | реестр задач, шаблон, история ID |
| [`doc-meta.json`](doc-meta.json) | тип и владелец документа |

## Правила

- Метаданные не заменяют текст документа.
- `doc-meta.json` обновляется при добавлении документа в `docs/`.
- Задача без критериев приёмки не переходит в `now`.
