# Примеры

| Файл | Что показывает |
|---|---|
| [`project-min.yaml`](project-min.yaml) | минимальный проект, который понимает `model.load()` |
| [`task-format.yaml`](task-format.yaml) | все поля задачи и строка связи |

Основной проект — [`../project.yaml`](../project.yaml). Примеры не участвуют в
сборке `out/`: это шаблоны для новой темы или для проверки формата.
