# 1. Назначение и состав работы

СРС расширяет лабораторные работы 1–9 заданиями из методических указаний, которые не входят в обязательный минимум: встроенные календари, учебные файлы, типы задач, профили загрузки, четырёхуровневый СДР, таблицы норм затрат, выравнивание, настраиваемые поля PERT и сценарии сокращения критического пути. Каждое задание оформляется отдельным .mpp и снимком экрана; отчёт собирается командой `python build_siw.py`.

Проект: «Организация научно-практической конференции» (CONF-2026). Плановый срок: 05.10.2026 — 19.11.2026; фаз — 5, работ — 17, вех — 5, ресурсов — 9. Стоимость по таблице A — 484 750,00 ₽.

Источник заданий — файл `siw\siw.yaml`. Он же связан с генератором `build_siw.py`: правьте YAML, а не готовый .docx.

## 1.1. Что сдаётся

- отчёт `out/siw-report.docx` с выполненными заданиями и скриншотами;
- отдельные `.mpp` для учебных файлов и промежуточных состояний плана;
- скриншоты `automation/results/shots/siw_lrN_KK.png`;
- устные ответы по контрольным вопросам каждого задания.

## 1.2. Как выполнять

1. Соберите базовый план: `python build.py`.
2. Откройте XML или .mpp в MS Project и выполняйте задания по порядку.
3. Сохраняйте промежуточные файлы под именами `siw_*`; не перезаписывайте базовый план.
4. Снимайте экран в моменты, указанные в задании; ID снимка — `siw_lrN_KK`.
5. Соберите отчёт: `python build_siw.py`, затем вставьте снимки `python -m automation.fill_report --src out/siw-report.docx --dst out/siw-report-final.docx`.
